# AGENTS.md

Инструкции для AI-агентов (например, Jules), которые работают с этим репозиторием.

## Назначение репозитория

Публичное портфолио начинающего системного аналитика. Читатель: HR и руководитель практики в IT, телекоме, нефтегазе.

## Правила

1. Язык документов: русский. Технические термины допускаются на английском.
2. Диаграммы только в Mermaid, чтобы они отображались на GitHub.
3. Ничего не выдумывать про реальный проект Team Task Manager. Если факт не подтверждён кодом или README проекта, помечать как **Допущение**.
4. Гипотетический кейс (`02-maintenance-requests`) всегда явно помечен как учебный. Не выдавать его за реальный опыт.
5. Нумерация требований сквозная внутри кейса: `BR-`, `FR-`, `NFR-`, `US-`, `TC-`.
6. Каждая user story содержит acceptance criteria в формате Given / When / Then.
7. Не удалять раздел «Допущения и открытые вопросы».
8. Один pull request на одну задачу из `ROADMAP.md`.

## Проверка перед PR

- Mermaid-блоки валидны (проверить в превью GitHub).
- Внутренние ссылки между файлами работают.
- Идентификаторы требований не дублируются и все `TC-` ссылаются на существующие `FR-`.
